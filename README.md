## 📂 Arquivos da Pasta
- `index.html` & `dashboard_prospeccao.html` : Dashboards interativos com 3.000 leads.

- `base_prospeccao_prx.csv` : Planilha Master com 3.000 leads e 24 colunas (UTF-8 BOM).

- `segmentos_icp/` : Pasta com as planilhas segmentadas por nicho e lotes de expansão.
- `bdr_prx_protocol.md` & `sdr_prx_protocol.md` : Protocolos operacionais e scripts comerciais.
- `INSTRUCOES_DE_USO.txt` : Manual de instruções para uso rápido.
